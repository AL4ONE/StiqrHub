# Stiqrhub FE

This frontend project runs on React and Vite with hot module replacement and the standard ESLint setup provided by Vite.

## Getting Started

```bash
npm install
npm run dev
```

To create a production build run `npm run build`; preview it locally with `npm run preview`.

## Tooling

- `vite` for development and bundling
- `@vitejs/plugin-react` for React Fast Refresh
- ESLint and Prettier for linting/formatting
